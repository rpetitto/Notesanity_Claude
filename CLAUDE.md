# Fling Project

This is a Fling project - a Small Software platform for building and deploying personal tools with a React frontend, API backend, SQL database, storage, and more.

Read the `fling` skill in detail!

## Deployment

Always log in to Fling as **robert@unropedapps.com** — not the account email
Claude Code reports for the session. Use
`npx fling login --email robert@unropedapps.com`, which sends a magic link and
waits for it to be clicked.
